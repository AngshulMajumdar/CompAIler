Sparse integer matrix service. Input q<=20 operations. TRANS r c na is followed by na triplets row col value for A; print A transpose. ADD r c na nb is followed by na triplets for A then nb for B (both r-by-c); print A+B. MUL r k c na nb is followed by A's na triplets (r-by-k) then B's nb triplets (k-by-c); print A*B. Dimensions 1..8, counts 0..100, coordinates zero-based and in range, entries magnitude <=100000. Duplicate coordinates in each input are SUMMED; explicit zero entries and zero sums must be omitted from output. Use exact 64-bit arithmetic. For every result print 'rows columns nnz', then nnz rows 'row col value' in increasing row then column order. Separate values by one space and end every record with newline.
