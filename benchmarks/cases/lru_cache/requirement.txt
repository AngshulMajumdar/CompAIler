LRU cache. Input capacity q, capacity=1..20 and q<=200, then q commands. Keys and values are signed integers of magnitude <=1000000. PUT key value inserts or replaces; an existing key's value is replaced and it becomes most recently used. A new key at full capacity evicts the least recently used key. PUT prints OK. GET key prints its value and makes it most recently used, or MISS and leaves the cache unchanged. DEL key prints OK and removes it, or MISS if absent. RESIZE capacity (1..20) changes capacity, repeatedly evicting least-recently-used entries if needed, and prints OK. CLEAR empties the cache and prints OK. SIZE prints the number of entries. KEYS prints count followed by keys in MOST-to-LEAST-recent order on one line, single spaces, with just 0 when empty. All command output ends with newline.
