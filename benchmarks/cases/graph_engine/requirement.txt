Directed weighted graph service. Input n m q, n=1..32, m<=100, q<=100. Next m rows are u v w, then q commands. Vertices are 0..n-1; weights 0..1000000. Parallel edges retain their minimum weight, including EDGE updates. Self-distance is zero; edges are directed. EDGE u v w adds/min-updates an edge and prints OK. DIST s t prints exact shortest distance or INF if unreachable. ALL s prints n shortest distances in vertex order, separated by single spaces, using INF. BFS s t prints minimum number of edges ignoring weights (zero-weight edges are valid), or -1 when unreachable; BFS s s is 0. REACH s counts reachable vertices INCLUDING s. ROUND s prints the sum of all shortest distances from s if every vertex is reachable, otherwise INF. RESET removes all edges, preserving n and zero self-distances, and prints OK. Output each command's result on one line.
