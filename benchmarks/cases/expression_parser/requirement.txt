Integer expression evaluator. Input t (0..40) on first line, followed by t complete expression lines, each at most 200 characters. Grammar supports unsigned decimal integer literals, spaces, parentheses, unary + and -, and binary + - * /. Unary signs bind most tightly, then * and /, then + and -. Binary operators associate left-to-right. Division truncates toward zero, including negative operands. Print the exact integer result for each valid line. Print ERROR for division by zero, invalid characters/tokens, empty expression, missing operand, unmatched parentheses or trailing unparsed text. Only these operators are allowed, not // or **. Permitted valid inputs have integer intermediates within signed 32-bit range. One result per line; do not print prompts.
