Gradebook. Read q (0..200), then q commands. Up to 100 students, IDs 0..1000. ADD id a b c adds an absent student with three marks 0..100. UPDATE id subject mark updates an existing student's subject indexed 0,1,2, rejecting other subject numbers or marks outside 0..100. DROP id removes an existing student. Mutations print OK or ERR and rejected mutations change nothing. SCORE id prints floor((2*a+3*b+5*c)/10), or ERR if absent. RANK prints student count then 'id score' rows sorted by decreasing score, breaking ties by increasing ID. SUMMARY prints 'count mean_score passing_count', where mean_score is floor of the mean of already-rounded student scores and passing_count counts scores >=50. Empty summary is '0 0 0'. Supplied invalid marks and subject indices must be rejected. One output record per line.
