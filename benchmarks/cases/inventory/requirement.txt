Inventory service. Input q (0..200), then q commands. At most 100 distinct items; IDs are integers 0..1000. Prices and quantities supplied to commands are integers in [-2,1000000]. ADD id price creates an absent item with zero stock; reject duplicates, negative price, or capacity overflow. RECEIVE id qty adds nonnegative qty to an existing item. SELL id qty subtracts nonnegative qty only if sufficient stock; exact-stock sales and zero-quantity sales are allowed. Successful sale adds qty*current_price to lifetime revenue. PRICE id price updates an existing item's nonnegative price. DROP id removes only an existing item with zero stock. These five mutating commands print OK on success, ERR otherwise and change nothing on failure. GET id prints 'id stock price' or ERR. LIST prints item count, then rows 'id stock price' in increasing ID order. TOTAL prints 'stock_value revenue', both exact 64-bit totals; stock_value=sum(stock*current_price). Revenue is not changed by price updates or deletion. Every output record ends with newline.
